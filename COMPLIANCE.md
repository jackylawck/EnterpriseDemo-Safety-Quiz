## 1. 政策聲明 / Policy Statement

企業示範組織（以下簡稱「本公司」）深知個人資料之重要性，並全力遵守相關法例（如香港特別行政區《個人資料（私隱）條例》PDPO 及 GDPR 核心精神）與國際資料保護實踐。本「企業入職安全訓練評估系統 Demo」（以下簡稱「本系統」）之運作嚴格秉持**「由設計保障私隱」（Privacy-by-Design）**及**「最小化資料收集」（Data Minimization）**原則。

Enterprise Demo Corp. ("the Company") is fully committed to protecting personal data privacy in compliance with relevant regulations (e.g., the Personal Data (Privacy) Ordinance of Hong Kong, core principles of GDPR) and international data governance best practices. The "Enterprise Demo Onboarding Safety Assessment System" ("the System") is designed in strict adherence to the principles of **Privacy-by-Design** and **Data Minimization**.

## 3. 資料留存政策（零資料留存架構） / Data Retention Policy (Zero-Data-Retention)

* **無伺服器端資料庫 (No Server-side Database)**：本系統不設永久性資料庫，亦不將員工個人資料儲存於雲端託管平台。
  The System does not have a persistent database and does not store employees' personal data on cloud hosting platforms.
* **記憶體即時處理 (In-Memory Processing)**：所有輸入資料僅於瀏覽器連線期間存在於臨時記憶體（Session State）中，生成 PDF 報告並完成發送後，記憶體即自動釋放重置。
  All input data exists only in temporary memory (Session State) during the browser session. Memory is automatically cleared immediately after the PDF report is generated and sent.
* **文件化受控存檔 (Documented Archiving)**：由系統生成之受控 PDF 文件（`DEMO-SED-REC-001`）直接傳輸至本公司專用安全郵箱 (`compliance@enterprise-demo.com`) 進行內部封閉存檔。
  The controlled PDF document generated by the System is transmitted directly to the Company's dedicated secure mailbox for internal closed-loop archiving.

---

## 4. 資訊安全與技術防護措施 / Information Security & Technical Measures (ISO/IEC 27001 Aligned)

1. **傳輸加密 (Encryption in Transit)**：全站強制採用 TLS 1.3 / HTTPS 傳輸協定。
   Mandatory use of TLS 1.3 / HTTPS protocols for all data transmission.
2. **金鑰隔離 (Secrets Isolation)**：系統通行碼（Access Code）、SMTP 發信憑證與題庫答案均由雲端環境變數（Secrets）保管，原始碼庫零機密暴露。
   Access codes, SMTP credentials, and quiz answers are managed via Cloud Environment Variables (Secrets), ensuring zero exposure in the source code repository.
3. **輸入消毒 (Input Sanitization)**：嚴格限制輸入字元長度並自動過濾惡意控制字元，防止注入（Injection）攻擊。
   Strict input length limits and automatic filtering of malicious control characters to prevent Injection attacks.
4. **防暴力破解 (Brute-Force Protection)**：內建登入錯誤次數限制機制，保障系統存取安全。
   Built-in limits on login attempts to secure system access against brute-force attacks.

## 2. 治理與架構技術合規要點 / Technical Governance & Compliance Points

### 2.1 零資料留存原則 / Zero-Data-Retention Principle

本系統作為輕量級前端 Web 介面，不架設任何外置儲存庫（No SQL / No NoSQL / No Cloud Storage Bucket）。所有資料流轉僅於記憶體中執行單次 PDF 渲染並即時發送，保障員工私隱不受雲端託管端洩漏威脅。
As a lightweight frontend web interface, the System does not utilize any external storage repositories (No SQL / No NoSQL / No Cloud Storage Buckets). All data flow is processed in-memory for a single PDF rendering and immediate transmission, protecting employee privacy from cloud hosting leak threats.

### 2.2 審計追蹤與不可否認性 / Auditability & Non-Repudiation

* 每份 PDF 報告自動標註標準時間戳 (Timezone Normalized Timestamp)。
Every PDF report is automatically stamped with a standardized timestamp.
* 每份報告完整列印受試者之每題實際提交答案與得分判定。
Every report fully details the subject's submitted answers for each question and the scoring evaluation.
* 包含受試者個人誠信獨立填答聲明，滿足 IMS 內部審計稽核標準。
Includes a personal integrity declaration of independent completion by the subject, satisfying IMS internal audit standards.

### 2.3 變更與維護管控 / Change & Maintenance Management

題庫與合格標準統一由安環組主管（SED Manager）於後台環境設定檔（`QUESTIONS_JSON`）維護，程式原始碼倉庫（Source Code Repository）嚴禁硬編碼任何業務機密，符合安全開發生命週期（SDLC）規範。
The quiz bank and passing criteria are centrally managed via backend environment configurations (`QUESTIONS_JSON`). Hardcoding any business secrets into the Source Code Repository is strictly prohibited, aligning with Secure Software Development Life Cycle (SDLC) standards.
